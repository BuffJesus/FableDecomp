# Retail frontend input value adapter

`fable_frontend_input_bridge` decodes one explicit 52-byte little-endian retail
event snapshot into an owned `presentation::FrontEndInputEvent`. It is available
in every modern configuration, before the existing reconstructed-prefix adapter
guard. It does not access native objects, poll devices or construct an input
manager. A caller supplies a valid byte span; no span or pointer is retained.

The adapter has its own public root, `integration/frontend/include`. Its public
interface links presentation; platform calibration is a private implementation
dependency. An explicit portable architecture policy rejects native/backend
includes and undeclared links. The existing integration adapter include root
remains separate, and presentation gains no dependency on platform/integration.

The complete record extent is checked before any field access. Wrong extents
return `bad_extent`; invalid raw joystick-position axes return
`invalid_stick_axes` before producing an event. Finite axes individually in
[-1,1] use the independently qualified checked platform transform. Rejecting
other joystick values deliberately strengthens behavior outside the native
comparison domain. Other event kinds do not interpret unused raw axis words.

Key identifiers remain raw frontend IDs with copied device/time metadata.
Characters keep the low UTF-16 code unit, including surrogates. Mouse movement,
wheel floats, all basic/extra button phases and unsigned joystick device/button
values become typed owned values. Unsupported/frontend-ignored event kinds
become `FrontEndIgnoredInput`; null and unknown nonzero types are intentionally
not distinguishable in this consumer value. A future queue must retain a
separate null marker if it needs the native scan-next semantics.

Decoding is stateless, nonallocating and noexcept. Sources/results can have
independent lifetimes; source mutation/destruction and subsequent calls do not
change retained results. The adapter adds no key translation, dead zone,
axis inversion, event-production timing, host callbacks or backend behavior.
