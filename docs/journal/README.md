# Journal and preserved history

Use [the current handoff](../HANDOFF.md) for lane ownership, current instructions and resume pointers. [The journal index](INDEX.md) lists dated records.

Older ACTIVE, PAUSED, next-task and numeric statements describe their checkpoint. Retaining a receipt does not rerun or recertify it. Current owner journals are single-writer records; coordinate before editing them.

Documentation cleanup preserves long originals as raw `.txt` files with SHA-256 hashes in dated history wrappers. The raw extension preserves original relative paths as text rather than turning them into misleading relocated links. No evidence is discarded by compaction.
