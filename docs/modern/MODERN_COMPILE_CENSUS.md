## x86 layout drift (`--layouts --arch x86`)

The same headers compiled for **x86** with the current compiler: **0 of 1505**
size-asserted classes change size at the same pointer width, with 0 headers failing otherwise. Any class listed in
[X86_LAYOUT_DRIFT.tsv](X86_LAYOUT_DRIFT.tsv) embeds a VC7.1 standard-library type whose current layout differs.
The generated engine headers model library members by their PDB size, so they do not depend on the
current library. The step-1 layout breaks seen in the TU pass come from hand-written shared headers
(`std::bitset<274>` in `fable_world.h`).
