# Seam scaffolds

Behaviourally faithful, **not byte-exact** bodies for near-miss functions, linked only by
`tools/decomp_pipeline/play_seam.py` so the CGame::Play seam can run past them. They are
scaffolding: never landed, never counted, never referenced by `build_bootstrap.ps1` or any
catalog. Each file names its retail address and why it is not landed; delete it when that
function passes exact or near-match verification and its candidate-linked behavior fixture.

2026-09-26: definition-string input, binary-definition loading, and string-map
lower-bound have graduated under the functional-first standard. Only the unsigned-long
vector assignment remains here; it is still below the near-match thresholds.
